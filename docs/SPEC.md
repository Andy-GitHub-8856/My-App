# 《天機命譜》規格書 v1.0

> 紫微斗數 × 八字 × 稱骨 · AI 解盤單檔網頁應用

## 1. 產品概述

| 項目 | 內容 |
|---|---|
| 形式 | 單一 HTML 檔（所有程式、樣式、排盤函式庫皆內嵌），雙擊即可在瀏覽器開啟 |
| 排盤 | 本機以程式計算，**離線可用**、結果可重現 |
| 解盤 | 透過 Claude API（使用者自備 API Key）串流產生詳細論斷 |
| 目標使用者 | 對命理有興趣的一般大眾與入門研究者 |
| 語言 | 繁體中文 |

### 核心原則：「排盤用程式，解盤用 AI」
AI 不負責安星、換算曆法。所有命盤資料由經驗證的開源函式庫計算，再以結構化 JSON 交給 AI，
並在系統提示中要求 AI **只能依據提供的盤面資料論斷，不得自行改動星曜位置**。

## 2. 技術架構

| 模組 | 技術 | 說明 |
|---|---|---|
| 曆法 / 八字四柱 / 大運 | `lunar-javascript` | 國曆↔農曆、節氣、干支、閏月、起運歲數 |
| 紫微斗數排盤 | `iztro` | 三合派安星、生年四化、大限、小限、流年四化 |
| 十神、藏干、納音、十二長生、五行計分 | 自行實作 (`src/bazi.js`) | 以繁體輸出 |
| 稱骨 | 自行實作 (`src/chenggu.js`) | 袁天罡稱骨表 + 稱骨歌 (2兩1錢～7兩1錢) |
| 真太陽時 / 夏令時 | 自行實作 (`src/solartime.js`) | 經度校正 + 均時差 |
| AI | `@anthropic-ai/sdk`（瀏覽器模式） | `claude-opus-5-5`，串流、可選 `claude-sonnet-5-5` |
| 打包 | `esbuild` + `build.mjs` | 將 JS/CSS 內嵌產出 `dist/tianji-mingpu.html` |

## 3. 輸入資料

| 欄位 | 必填 | 說明 |
|---|---|---|
| 姓名 / 暱稱 | ✓ | 顯示用 |
| 性別 | ✓ | 決定大限順逆、八字大運順逆 |
| 曆法 | ✓ | 國曆 / 農曆（農曆可勾選閏月） |
| 出生年月日 | ✓ | 1900–2100 |
| 出生時分 | ✓* | 可勾選「時辰不詳」：此時不排紫微盤，八字只排三柱，稱骨只計三項 |
| 出生地 | ✓ | 下拉選單（台灣各縣市、港澳、中國主要城市、海外主要城市）或「自訂經度 + 時區」 |
| 真太陽時校正 | 預設開 | 校正 = (經度 − 時區×15)×4 分 + 均時差 |
| 夏令時間 | 自動偵測 | 台灣 1945–1979、中國 1986–1991 的實施期間會自動勾選並提示，可手動修改 |
| 子時換日 | 預設「早晚子分」 | 選項：早晚子時分日（23–24 點日柱不換）／ 23 點即換日 |
| 想問的重點 | 選填 | 感情、事業、財運、健康、學業…，AI 會加重這些主題的篇幅 |

## 4. 排盤輸出

### 4.1 紫微斗數命盤（三合派 + 生年四化）
- 傳統 4×4 方格：外圍 12 宮（巳午未申 / 辰…酉 / 卯…戌 / 寅丑子亥），中間顯示基本資料
- 每宮顯示：宮名、宮干支、主星（含廟旺利陷）、輔星、雜曜、生年四化徽章（祿權科忌）、長生十二神、大限歲數
- 標示：命宮、身宮、**目前大限宮**、**今年流年命宮**
- 點選任一宮 → 高亮三方四正
- 中宮：姓名、國曆／農曆、四柱、五行局、命主、身主、校正後時間

### 4.2 八字
- 四柱表：天干、地支、藏干、十神（干／支藏干）、納音、十二長生（日主坐支）
- 五行力量長條圖（簡化計分：天干 1.0，藏干本氣 1.0 / 中氣 0.5 / 餘氣 0.3，月令 ×2）
- 日主強弱指標（同類＝比劫+印星 比例）、初步喜用神（供 AI 參考，AI 會結合格局與調候再論）
- 大運時間軸（起運歲數、每十年干支、目前大運高亮）

### 4.3 八字重量（稱骨）
- 年（農曆年干支）+ 月（農曆月）+ 日（農曆日）+ 時（時辰）四項骨重
- 顯示「X 兩 X 錢」、四項明細、稱骨歌原文

## 5. AI 解盤

### 5.1 解盤章節（每章獨立串流、可單獨重新生成）
1. 命格總論
2. 命宮與身宮（主星特質、性格、天賦）
3. 十二宮詳解（上）：命、兄弟、夫妻、子女、財帛、疾厄
4. 十二宮詳解（下）：遷移、僕役、官祿、田宅、福德、父母
5. 四化與格局（生年四化落宮、重要格局）
6. 大限與流年（目前大限、2026 丙午流年、近三年趨勢）
7. 八字命局（日主強弱、格局、喜用忌神、十神性格）
8. 八字大運流年
9. 稱骨論斷（古歌白話 + 現代詮釋）
10. 綜合建議與開運（個性、事業、財運、感情、健康、開運顏色／方位／行業）

「一鍵完整解盤」依序產生全部章節。

### 5.2 語氣
專業命理師口吻 + 白話解釋：先給術語依據（例如「命宮紫微天府同度，廟旺」），再白話說明對生活的意義。

### 5.3 AI 追問
解盤後可針對命盤自由提問，保留對話脈絡（多輪），命盤資料固定在 system prompt。

### 5.4 API 設定
- API Key 僅存在使用者瀏覽器 localStorage（可選擇不記住）
- 模型：`claude-opus-5-5`（預設）／ `claude-sonnet-5-5`
- 思考深度（effort）：中 / 高（預設）/ 極高
- 安全拒答時自動改用備援模型（server-side fallback），若帳號不支援則自動停用重試
- 使用 prompt caching：命盤 JSON 放在 system 前段並加 `cache_control`，降低多章節成本

### 5.5 防護
- System prompt 要求：只依提供資料論斷、不捏造星曜、避免醫療/投資/法律斷言、命理僅供參考
- 錯誤處理：401（Key 錯誤）、429（頻率限制）、網路錯誤、拒答，皆以中文提示

## 6. 存檔與匯出
- 命盤存檔：多人命盤存於 localStorage（含已生成的解盤內容），可載入、刪除
- 匯出 / 匯入 JSON
- 列印 / 存 PDF：專用列印樣式，排成「命書」格式（封面、命盤、八字、稱骨、全部解盤）

- 色彩：夜空深藍→紫黑漸層、鎏金 (#d4af37)、朱砂紅、玉青
- 背景：Canvas 星點閃爍 + 緩慢流星
- 開場：SVG 旋轉八卦羅盤（後天八卦 + 十二地支 + 二十八宿環），排盤時加速
- 字體：Noto Serif TC（內文）、LXGW WenKai TC（標題），離線時退回系統襯線字
- 卡片：半透明玻璃質感 + 金色細框 + 光暈
- AI 文字逐字浮現
- RWD：手機 16px 邊距、命盤容器可橫向捲動、頁面本身不橫向捲動
