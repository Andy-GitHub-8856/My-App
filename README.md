# 天機命譜 ✦ 紫微斗數 · 八字 · 稱骨 · AI 解盤

單一 HTML 檔的命理網頁應用。輸入生辰後，在本機精確排出紫微斗數命盤、八字四柱與稱骨，再透過 Claude AI 撰寫詳細的解盤報告。

## 使用方式
1. 下載 [`dist/tianji-mingpu.html`](dist/tianji-mingpu.html)，用瀏覽器（Chrome / Edge / Safari）直接開啟。
2. 輸入姓名、性別、生辰與出生地，按「起盤」。排盤不需要網路。
3. 要用 AI 解盤時，先到右上角「設定」輸入 Claude API Key（可到 console.anthropic.com 申請）。Key 只會存在你自己的瀏覽器裡。
4. 到「AI 解盤」分頁按「一鍵完整解盤」，或是逐章生成；也可以在「AI 追問」分頁繼續提問。
5. 「儲存命盤」會連同解盤內容一起保存；「列印／PDF 命書」可以輸出成精美的命書。

## 功能
- 紫微斗數（三合派 + 生年四化）：12 宮方格盤，標出廟旺利陷與四化，可點選查看三方四正，並標示目前大限與今年流年
- 八字：四柱、十神、藏干、納音、十二長生、五行力量、日主強弱、大運
- 稱骨：袁天罡稱骨法與稱骨歌
- 真太陽時校正（經度 + 均時差）、自動偵測台灣（1945–1979）與中國（1986–1991）的夏令時間、可選早晚子時的換日方式
- AI 解盤共 10 章，加上多輪追問；使用 Claude Opus 5.5（可改用 Sonnet 5.5）並串流輸出
- 命盤存檔、匯出／匯入 JSON、列印成命書

## 開發
```bash
npm install
npm run build   # 產出 dist/tianji-mingpu.html
```
