# 台股篩選器

純 HTML + 原生 JavaScript 的台股篩選器，直接用瀏覽器開啟 `index.html` 就能執行（不需要 npm、打包工具或框架）。行情資料來自 [FinMind](https://finmindtrade.com/) API。

## 功能

- 預設 20 支熱門台股觀察清單，可用代號或名稱新增、按 × 刪除（存在瀏覽器 localStorage）
- 每支股票依四個面向評分（0–100），加權成綜合分數並給予 A+ ~ E 評級
  - 技術面 30%：均線排列、20 日動能、RSI(14)
  - 估值面 25%：本益比、股價淨值比、殖利率
  - 成長面 25%：月營收年增率、近 3 月累計年增率
  - 籌碼面 20%：近 10 日三大法人買賣超佔成交量比例
- 預設依綜合分數由高到低排序（最值得投資的排最前面），也可以改依其他面向排序、依評級篩選
- 走勢迷你圖、紅漲綠跌、深色模式、手機版排版
- 行情快取 30 分鐘，可在「設定」填入 FinMind token 提高請求上限

## 檔案

- `index.html`：頁面結構
- `style.css`：樣式
- `app.js`：資料抓取、指標計算、評分與畫面

> 本工具僅依公開數據做量化計算，不構成投資建議。
