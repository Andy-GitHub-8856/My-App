# 小記帳 💰

一個免安裝、純前端的精美記帳小工具，附收支彙整分析頁面。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可（或在專案目錄執行 `python3 -m http.server` 後開啟 http://localhost:8000 ）。
資料儲存在瀏覽器的 localStorage，不會上傳到任何伺服器。

發佈到 claude.ai 時，紀錄會另外同步到你帳號底下的私有空間（每月一份文件），只有你自己看得到，換手機、換電腦開同一個連結都看得到同一本帳。

## 功能

**記帳頁**
- 支出 / 收入快速記帳：金額、分類（附圖示）、日期、備註
- 本月收入、支出、結餘摘要卡，可設定每月預算並顯示使用進度
- 依日期分組的明細，支援搜尋、編輯、刪除（可復原）
- 上 / 下個月切換，點月份標題回到本月

**分析頁**
- 本月 / 全年、支出 / 收入切換
- 關鍵指標：總額（與上一期同期比較）、結餘、日均、儲蓄率
- 分類佔比條與排行（含筆數、與上期比較）
- 每日支出長條圖（含日均線）
- 近 6 個月（或全年每月）收支對照
- 星期分布、單筆最高排行
- 所有圖表皆可滑鼠懸停 / 鍵盤聚焦查看數值

**其他**
- 深色 / 淺色模式（預設跟隨系統）
- 匯出 CSV（Excel 可直接開啟）、JSON 備份與還原
- 第一次開啟先顯示示範資料（不會儲存），記下第一筆後換成自己的帳本
- 手機版面最佳化

## 檔案結構

```
index.html      頁面結構
css/style.css   樣式（含深色模式）
js/app.js       記帳邏輯、分析計算與 SVG 圖表
```
