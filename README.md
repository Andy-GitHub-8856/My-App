# 天氣儀表板

用純 JavaScript（不需要安裝或打包）做的天氣儀表板。

## 功能

- **自動抓取最新天氣**：資料來自 [Open-Meteo](https://open-meteo.com/)，免 API 金鑰，每 10 分鐘自動更新；切回分頁時如資料過舊也會立即更新
- **輸入地區切換**：搜尋框支援中文／英文地名，附自動完成建議（↑↓ 選擇、Enter 確認）
- **目前位置**：點 ◎ 按鈕用瀏覽器定位
- 目前天氣、體感、最高／最低溫與今日摘要
- 未來 24 小時溫度曲線與降雨機率
- 七日預報（含溫度區間條）
- 空氣品質（美國 AQI、PM2.5、PM10、臭氧）
- 今日詳情：濕度、風向風速、紫外線、氣壓、能見度、雲量、日出日落
- °C / °F 切換、最近查詢的地區（存在瀏覽器中）
- 背景會依天氣與日夜變化，支援手機版面

## 使用方式

直接用瀏覽器開啟 `index.html` 即可。或啟動本機伺服器：

```bash
npx serve .
```

## 檔案

- `index.html` — 頁面結構
- `style.css` — 樣式
- `app.js` — 抓資料與繪製邏輯
